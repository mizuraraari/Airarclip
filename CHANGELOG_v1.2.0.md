# AI AUTO EDITOR v1.2.0

## New in this build
- Added two subtitle templates: **Pop Cyan** and **Compact**.
- Added three creative color presets: **Anime**, **Gaming**, and **Vlog**.
- Kept the existing Auto, Cinematic, Energetic, and Clean choices.
- Presets are deterministic FFmpeg color/sharpening filters. They do not generate new animation, character art, or game footage.

## Notes
- The Android screen exposes the new choices in the subtitle and Creative Mode selectors.
- New presets are applied during cloud finalization; the app can still export a basic local MP4 if cloud finalization is not configured.
- This is source code, not a compiled APK. Build and test on a real Android device before distribution.
